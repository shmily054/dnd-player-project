# D&D 5E 角色卡 + 规则库 — 实施方案

## 1. 可行性结论

可行，且数据质量足够支撑完整体验：

- `database` 共 61 MB，其中 PDF 占 56 MB，真正要检索的正文只有约 2.3 MB（33 个 Markdown，玩家手册 288 页 + 城主指南 290 页）。
- 约 355 条法术、245 条魔法物品、42 个专长、15 种状态、护甲/盾牌/武器表、12 职业成长表，都有稳定文本模式，可解析为结构化条目。
- 旧 `player card` 应用已验证「本地 Node 服务 + Markdown 检索 + JSON 存档」路线可行；新项目会重写其薄弱部分。
- 主要风险是两栏 PDF 提取造成的偶发串行、职业表跨页断行。对策：解析报告 + 人工校对覆盖文件 + 原文全文检索兜底，不依赖单一解析结果。

## 2. 已确认范围

- 在空目录 `player card ds` 全新构建。
- 导入旧角色「查士丁尼」及其头像，作为首个角色。
- 本地 Web 应用：双击 `start.bat` 启动，浏览器访问，数据保存到磁盘并自动备份。
- 规则库：结构化条目 + 全文检索 + 一键按正确数据插入 + 升级向导。
- 附加模块：角色扮演档案、规则速查。
- 明确不做（按你的选择）：骰子台/掷骰记录、A4 打印/PDF/Markdown 导出、在线同步、2024 规则。保留基础 JSON 备份/导入/恢复作为数据安全功能。
- 规则库只读，不修改 `database` 原文件；所有卡面数据可手动编辑，数据库只是辅助，不构成限制。

## 3. 技术架构

- 前端：React 19 + TypeScript + Vite 7 + Tailwind 3.4 + lucide-react + zod。
- 不引入整套 shadcn/Radix：弹窗用原生 `<dialog>`，折叠用 `<details>`，下拉用原生 `<select>`，减少依赖和维护面。
- 后端：Node 20 内置 `http`/`fs`，无 Express；开发模式挂 Vite middleware，生产模式服务 `dist/`。
- 测试：Vitest（纯函数、解析器、API）。
- 仅绑定 `127.0.0.1`，不对外网开放。
- 默认端口 7100；被占用时自动向后寻找可用端口，并由服务端自动打开浏览器。
- 数据库路径默认 `../database`（相对项目根），可在设置页修改并重建索引。

## 4. 角色数据与存档

- 每个角色一个 JSON：`data/characters/<id>.json`，便于手动查看/备份/版本管理。
- 保存采用临时文件 + rename 原子写入；每次覆盖前备份，保留最近 30 份。
- zod 校验写入数据；损坏的存档不覆盖，返回明确错误。
- 前端 800 ms 防抖自动保存，显示「已保存/保存中/有改动」；关闭页面前有未保存提醒。
- 支持 JSON 导入/导出、复制角色、从备份恢复；设置页显示存档路径与备份列表。
- 支持外部手动修改 JSON 后点击「刷新」重新读取。
- 头像在浏览器端缩放到最长边 512 px 后上传，存 `data/portraits/`。

### 核心数据模型（简化）

```ts
interface Character {
  schemaVersion: 1
  id: string; name: string; playerName: string; portrait: string | null
  classes: { name: string; subclass: string; level: number; hitDie: number }[] // 支持兼职
  race: { name: string; subrace: string }; background: string; alignment: string
  xp: number
  abilities: Record<'str'|'dex'|'con'|'int'|'wis'|'cha', number>
  saveProfs: AbilityKey[]; skillProfs: string[]; skillExpertise: string[]
  toolProfs: string[]; languages: string[]; armorProfs: string[]; weaponProfs: string[]
  hp: { max: number; current: number; temp: number }
  hitDice: { remaining: number }                    // 总数为所有职业等级之和
  ac: { mode: 'auto'|'manual'; manual: number | null }
  initiative: { mode: 'auto'|'manual'; manual: number | null }
  speed: number; exhaustion: number
  conditions: { name: string; level?: number }[]
  concentration: string | null
  spellcasting: {
    ability: AbilityKey
    slots: Record<number, { total: number; used: number; manual?: boolean }>
    pactSlots?: { total: number; used: number; level: number }
    spells: SpellEntry[]
  }
  attacks: Attack[]; resources: Resource[]; inventory: Item[]; currency: Currency
  features: Feature[]
  roleplay: { personality: string; ideals: string; bonds: string; flaws: string;
              appearance: string; backstory: string; allies: string; notes: string }
  createdAt: number; updatedAt: number
}
```

- 总等级 = 各职业等级之和；升级向导默认逐职业升级。
- 所有派生值实时计算，不重复存储：属性调整值、熟练加值、豁免、技能、被动察觉/调查/洞悉、法术豁免 DC、法术攻击、AC 分解、先攻、负重、法术位上限、准备法术上限、XP 进度、生命骰总数。
- 每个派生值显示计算依据；AC、先攻、HP、法术位均可切换为手动覆盖，避免规则判断影响自定义角色。

## 5. 规则库：结构化 + 全文

### 5.1 解析范围

| 类型 | 规模 | 解析依据 | 用途 |
|---|---|---|---|
| 法术 | 约 355 | 名称行 + `N环 学派` / `学派 戏法`；施法时间、距离、成分、持续时间；仪式/专注标记；升环效应 | 筛选、详情、一键加入 |
| 法术职业列表 | 8 个施法职业 | 章节开头 `X环` + 法术名列表 | 标注法术所属职业，升级/添加时校验 |
| 魔法物品 | 约 245 | 名称行 + `类型,稀有度`；`需同调` | 加入物品栏、稀有度筛选 |
| 专长 | 42 | 以 PHB 专长英文名清单锚定条目，解析先决条件与正文 | 加入特性、升级时选专长 |
| 状态 | 15 | 附录 A 名称行 + 项目符号 | 状态选择器、状态说明 |
| 护甲/盾牌 | 12 + 1 | 护甲表列：AC、力量、隐匿、重量 | AC 自动计算 |
| 武器 | 约 37 | 武器表：价格、伤害骰/类型；属性与重量校对 | 生成攻击条目 |
| 职业成长 | 12 × 20 | 职业表 + 施法表 + 特性段落 | 升级向导、法术位、资源 |
| 其他章节 | 全部 | 原文 Markdown | 全文检索兜底 |

- 职业成长数据由脚本从 DB 生成初稿，再人工校对成 `shared/classes.json`；标准法术位表单独校验。圣武士示例：4 级 3 个 1 环法术位；5 级 4 个 1 环 + 2 个 2 环，并获得额外攻击。
- 子职业只结构化名称与所属职业；具体子职业特性在升级时提示并链接规则库，不强行自动填充，避免解析错误。
- 生成 `compendium-report.json`：各类条目数、解析失败条目、疑似缺字段、原文位置。解析失败不阻塞使用，始终可回退到全文检索和手动添加。

### 5.2 检索体验

- 全局入口：顶栏「检索规则库」按钮 + `Ctrl/Cmd+K`；各区块的「搜索添加」按钮直接打开对应类型。
- 类型页签：全部 / 法术 / 魔法物品 / 专长 / 状态 / 装备 / 规则全文。
- 筛选：法术按环位、学派、职业、仪式、专注；物品按稀有度、类型；支持书籍/章节过滤。
- 排名：标题精确 > 标题包含 > 标题/正文出现次数 > 正文；中文子串 + 英文名均可搜（如「火球」和「Fireball」）。
- 结果展示：类型徽章、关键属性、命中片段高亮、PDF 页码、所属章节；详情面板显示完整条目和「原文上下文」。
- 一键插入：
  - 法术：自动填入环位、学派、施法时间、距离、成分、持续时间、专注/仪式、描述、职业；不要求手填环位。若当前等级无法施放或不在职业列表，给出提示但允许加入（支持自定义）。
  - 魔法物品：填入类型、稀有度、同调、描述；默认未装备/未同调。
  - 武器/护甲：填入伤害、攻击属性、AC、重量；武器可同时生成攻击条目。
  - 专长：作为特性加入，附先决条件与描述。
  - 状态：直接切换状态；力竭单独 0–6 级记录。
- 规则库浏览页：按类型浏览全部条目，不只依赖关键词搜索；适合跑团前准备。

### 5.3 数据质量处理

- 「覆盖文件」只修正解析器难以判断的条目（名称、环位、稀有度、边界），不复制整库文本。
- 已知问题：第 5 章装备说明和第 7 章宝藏说明存在两栏串行；结构化字段取自表格/条目头，正文展示原文并标注页码，必要时以原文为准。
- `{{p.N}}` 是 PDF 页码，不是印刷页码；界面统一标注「PDF 第 N 页」。
- 状态名称以附录 A 为准：目盲、魅惑、耳聋、恐慌、擒抱、失能、隐形、麻痹、石化、力竭、中毒、倒地、束缚、震慑、昏迷（旧应用中的「被擒/隐身」等偏差会修正）。
- 解析测试固定断言关键样本：火球术（3 环/塑能/150 尺）、警报术（1 环/仪式）、英雄宴（6 环）、警觉（先攻 +5）、板甲（AC 18/力量 15/隐匿劣势/65 磅）、15 种状态齐全。

## 6. 角色卡功能

### 6.1 卡面区块

1. **身份与头像**：姓名、玩家名、种族/子种族、职业/子职业/等级（支持多职业）、背景、阵营、XP 与升级进度、头像上传。
2. **属性/豁免/技能**：六属性及调整值、熟练加值、六豁免、18 技能（熟练/专精切换）、被动察觉/调查/洞悉、工具/语言/护甲/武器熟练。
3. **战斗**：当前/最大/临时 HP、AC（自动分解：护甲 + 敏捷 + 盾牌 + 特性，或手动覆盖）、先攻、速度、生命骰、死亡豁免三成功/三失败、力竭等级、状态、专注。
4. **攻击**：武器攻击表，显示命中加值、伤害骰与类型、射程/触及、属性、熟练、魔法加值；点击武器可查看来源物品。可从装备库添加或自定义。
5. **法术**：施法属性、法术豁免 DC、法术攻击加值、各环法术位刻度（可点已用/恢复）、契约魔法位、准备法术上限、法术列表按环位分组；标记准备/常备/专注/仪式；一键从规则库按职业与环位筛选添加。
6. **资源**：圣疗池、引导神力、怒气、气、术法点等；显示总/已用/恢复方式（短休/长休/不恢复），支持自定义资源。
7. **物品与财富**：数量、单位重量、总重量、负重上限/负重状态、装备/同调开关（同调上限 3）、价格与来源；金币五档换算；护甲/盾牌参与 AC，武器可生成攻击。
8. **特性与专长**：按来源分组（种族/职业/背景/专长/其他）；可附使用次数与恢复方式；升级新增特性自动带「查看规则」入口。
9. **角色扮演档案**：性格特质、理想、羁绊、缺陷、外貌（年龄/身高/体重/眼睛/皮肤/头发）、背景故事、盟友与组织、备注。
10. **短休/长休**：
    - 短休：选择花费生命骰并输入治疗量（或按平均值），恢复短休资源、契约法术位。
    - 长休：HP 回满、法术位全恢复、长休资源恢复、生命骰恢复一半（至少 1）、力竭 -1、死亡豁免清零、清除专注；弹窗列出变化摘要。
11. **其他**：自动保存状态、备份恢复、导入/导出、设置（数据库路径、索引重建、主题）。

### 6.2 交互与视觉

- 全卡内联编辑，无独立「编辑模式」；数字输入支持滚轮/步进，刻度可直接点击。
- 桌面双栏 + 锚点导航；移动端单栏 + 底部导航（角色/法术/物品/特性/规则/速查）。
- 羊皮纸浅色主题 + 墨夜深色主题；衬线标题、墨绿与金色点缀；只用系统字体，离线可用。
- `Ctrl/Cmd+K` 检索，`Ctrl/Cmd+S` 立即保存，`Esc` 关闭弹层。
- 所有列表可手动增删改、排序；数据库条目只作为快捷入口。

## 7. 升级向导

- 入口：顶栏「升级」；XP 达到阈值时高亮，未达标也可手动升级并提示。
- 步骤：
  1. 选择要提升的职业（默认唯一职业）。
  2. 预览：新等级、熟练加值变化、新职业特性、法术位/戏法/已知法术变化、属性提升等级、子职业选择等级、资源上限变化。
  3. 选择 HP 增长：职业生命骰平均值 + 体质调整值，或手动输入掷骰结果。
  4. 属性提升（4/8/12/16/19，战士额外 6/14，游荡者 10）：+2 一项 / +1 两项 / 选择一个专长（从规则库检索加入）；属性上限 20。
  5. 子职业等级（如圣武士 3 级）：从该职业子职业列表选择，添加占位特性和规则库链接。
  6. 应用：先创建角色备份，再更新等级、HP 上限与当前值、生命骰、法术位、资源、特性；弹出升级摘要。
- 新特性描述采用「按名称在职业章节检索并摘录」的方式自动填充，标注「自动摘录，请核对」；失败则保留「查看规则」链接。
- 圣武士 4→5 的验收示例：熟练加值 +3、获得额外攻击、1 环法术位 3→4、新增 2 个 2 环法术位、HP 按平均值 +8（d10+2）。
- 兼职：数据模型支持；向导逐职业升级；多施法者法术位合并 v1 以手动校验为主，避免规则误算。
- 升级后可通过备份恢复回滚。

  - 引导神力记录为 2 次/短休；PHB 圣武士为 1 次/短休（「引导神力」原文：使用后须完成短休或长休才能再次使用）。
