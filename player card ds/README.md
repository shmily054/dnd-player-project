# D&D 5E 角色卡 · 规则库

一个本地运行的 D&D 5E（2014 规则）角色卡应用。角色数据保存在本机 JSON 文件里，规则库直接读取隔壁的 `database` 文件夹（玩家手册 + 城主指南中文文本）。

## 启动

双击 `start.bat`。首次运行会自动安装依赖并构建前端，之后启动本地服务并打开浏览器。

也可以手动：

```bash
npm install
npm run dev        # 开发模式，http://127.0.0.1:7100/
npm run build
npm start          # 生产模式，自动打开浏览器
```

服务只绑定 `127.0.0.1`，不会暴露到局域网或公网。

## 主要功能

- **内联编辑**：姓名、等级、属性、技能、HP、AC、法术位、物品、特性、法术、角色扮演档案均可直接改，800ms 防抖自动保存。
- **规则库检索**：`Ctrl+K` 打开；支持中文/英文名、法术环位/学派/职业筛选、魔法物品稀有度、状态、装备和原文全文。
- **一键插入**：从规则库添加法术时会自动填入环位、学派、施法时间、距离、成分、持续时间、专注/仪式标记和描述；添加武器会同时生成攻击条目。
- **升级向导**：选择职业、HP 成长方式、属性提升或专长、子职业；自动更新熟练加值、法术位、职业特性与标准资源。
- **短休/长休**：自动恢复法术位、契约法术位和短休/长休资源，长休恢复一半生命骰、降低力竭。
- **角色扮演档案**：性格、理想、羁绊、缺陷、外貌、背景故事、盟友与战役笔记。
- **跑团速查**：动作、状态、休息、专注、掩护、旅行、DC 等常用规则卡片，附原文入口。
- **数据安全**：每个角色单独 JSON；每次保存前自动备份到 `data/backups/<角色 id>/`，保留最近 30 份；支持 JSON 导入/导出和备份恢复。
- **移动端**：响应式单栏 + 底部导航；羊皮纸/墨夜两种主题。

## 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+K` / `Cmd+K` | 打开规则库检索 |
| `Ctrl+S` / `Cmd+S` | 立即保存 |
| `Esc` | 关闭弹窗 |

## 数据位置

| 路径 | 内容 |
|---|---|
| `data/characters/<id>.json` | 角色存档，一个角色一个文件 |
| `data/backups/<id>/` | 自动备份，最多 30 份 |
| `data/portraits/` | 头像 |
| `data/compendium.json` | 生成的结构化规则库索引 |
| `data/compendium-report.json` | 解析覆盖报告与警告 |
| `data/settings.json` | 设置覆盖（数据库路径等） |

规则库默认指向 `../database`，可在「设置 → 规则库数据库」中修改，保存后会立即重建索引。

## 当前角色

首次构建时已从旧版 `player card` 导入「查士丁尼」（阿斯莫 / 圣武士 / 奉献之誓 4 级），并生成校对报告：

- 已修正：生命骰总数、英雄宴环位。
- 待确认：至圣斩是职业特性、准备法术数量、引导神力次数、技能熟练数量。
- 头像已迁移。

校对报告可以在角色卡顶部逐项处理或忽略。

## 规则库说明

- 数据来源：`database/player handbook`（288 页）和 `database/dungeon master guidance`（290 页）的 Markdown 全文。
- 解析器会生成约 355 条法术、243 条魔法物品、42 个专长、15 种状态、50 件护甲/盾牌/武器，以及 12 职业 × 20 级成长数据。
- 章节正文里的 `{{p.N}}` 是 PDF 页码，不是印刷页码；界面显示「PDF 第 N 页」。
- 两栏 PDF 提取偶尔会把正文左右栏串在一起；结构化字段来自条目头和表格，受影响的只是原文正文。检索始终可以回退到原文。
- 规则库是只读的，应用不会修改 `database` 下的文件。修改 Markdown 后在设置中点击「重建索引」即可更新。

## 开发与测试

```bash
npm test              # Vitest：数值、解析、检索
npm run db:build      # 重新解析 database → data/compendium.json
npm run db:classes    # 重新生成 shared/classes.json
npm run db:migrate-old # 重新导入旧角色（会覆盖 justinian01）
```

技术栈：React 19 + TypeScript + Vite 7 + Tailwind CSS 3；Node 内置 `http` 服务；无外部数据库或云服务。

## 已知限制

- 按需求没有做骰子台、A4 打印/PDF 或 Markdown 导出；攻击/技能只计算加值，掷骰使用实体骰或外部工具。
- 子职业特性不会逐条自动录入，升级时提供子职业选择和规则库检索入口。
- 兼职数据模型已支持；升级向导逐职业处理，多施法者合并法术位以手动校验为主。
- 仅覆盖 2014 版 PHB/DMG；不含 2024 规则、怪物图鉴扩展或其他 supplement。
